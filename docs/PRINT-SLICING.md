# Print slicing / Laminado

For an order's 3MF handoff, the slicing job calls `hub_print_slice` with the source `piece_id`, its own `task_id`, its Ágora identity and the space. The Hub uses its detected OrcaSlicer installation without opening a window. It reads the registered 3MF revision and records a G-code piece derived from it. When the slicer cannot produce G-code, it registers the failure report as the piece. The result includes `gcode_generated`, `checks_clear`, the piece, the receipt and log paths, and the undo tokens in application order. Pass them to `hub_agora_order_undo` in the given sequence to remove the defects and slice record.

Machine, process and filament paths are absolute paths to resolved OrcaSlicer preset JSONs, with filaments in slot order. The receipt records their names and SHA-256 hashes. Set `arrange: false` to keep the project's placement. For a multi-plate OrcaSlicer project, use the 1-based `plate` argument. Omit it when the input produces one plate. Set `expected_filaments` or `require_support` when those are requirements of the job. Use `supersedes` to record a new revision after a correction. Each visible warning or error from the run is recorded as a piece defect, even when the exit code is zero.

The slicer has 75 seconds by default. For a longer run, set `timeout_s`. When using the command-line tool, set its observation `--timeout` above the slicing budget.

The Orders gate and pending-decision card show total time from the G-code header and the material totals per slot from its footer. Support volume is the net positive extrusion on support and support-interface paths, converted with each filament's diameter. Filament changes use the G-code total where present or switches between deposited slots, plus explicit manual changes. Per-colour time estimates use distance and commanded feed rates on extrusion moves. They exclude travel, waiting, acceleration and tool-change operations. The colour labels come from the slicer's slot configuration. Reported visual colours in a 3MF only become print colours once the slicer assigns them to slots.

In OrcaSlicer 2.3.1 an empty bed exclusion area can trigger `calc_exclude_triangles:Unable to create exclude triangles` because the display triangulator is called with an empty polygon. The slicer reports this as an error and the receipt identifies the affected bed preview. Leave a valid printer preset with no exclusion area as configured. If the physical printer has an exclusion area, specify its real coordinates in the printer preset. [OrcaSlicer 2.3.1 source](https://github.com/OrcaSlicer/OrcaSlicer/blob/v2.3.1/src/slic3r/GUI/PartPlate.cpp)

## Castellano

El puesto de laminado llama a `hub_print_slice` con el `piece_id` del 3MF, el `task_id` del puesto, su identidad del Ágora y el espacio. El Hub usa el laminador instalado sin abrir una ventana y registra el G-code derivado de esa revisión. Si falla el laminado, registra el informe como pieza. La respuesta indica si hay G-code (`gcode_generated`) y si las comprobaciones quedaron sin incidencias (`checks_clear`). Incluye la pieza, las rutas del recibo y del registro y los tokens de deshacer. Pásalos a `hub_agora_order_undo` en el orden dado para retirar los defectos y el registro del laminado.

Indica las rutas absolutas a los perfiles JSON resueltos de máquina, proceso y filamentos. Introduce los filamentos por orden de ranura. Con `arrange: false` se conserva la colocación del proyecto. Para un proyecto con varias placas, selecciona la placa por número con `plate`. Deja ese campo vacío para un 3MF que produzca una sola placa. Con `expected_filaments` y `require_support` puedes hacer constar los requisitos del puesto. Usa `supersedes` para registrar una nueva revisión. Los avisos y errores del laminador se comunican como defectos de la pieza aunque su código de salida sea cero.

El laminador dispone de 75 segundos por defecto. Para una pasada larga, indica `timeout_s`. Si usas la herramienta de terminal, ajusta su tiempo de espera `--timeout` por encima del tiempo de laminado.

Las tarjetas de Órdenes y de Tus decisiones pendientes muestran el tiempo total del laminador y el material por ranura del G-code. El volumen de soportes se calcula a partir de la extrusión neta en sus trazados e interfaces. Los cambios se leen del resumen o de las transiciones entre ranuras que depositan material, más los cambios manuales explícitos. El tiempo por color estima el movimiento de los trazados con extrusión. Los colores son los de las ranuras del laminador. Un 3MF puede llevar colores de apariencia que requieran asignación de filamentos.
